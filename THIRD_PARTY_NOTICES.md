# Third-party components

Current scaffold runtime uses only Python's standard library. Build packaging uses setuptools; REA was a research-time tool and is not a runtime dependency or redistributed executable.

The root MIT license covers original Vyana contributions. It does not relicense Nanobot or other upstream materials. Nanobot's root code is MIT; its packaged UI fonts/assets and native TUI release archives have additional notices. Retain and audit the exact applicable notices before copying/building/distributing those components.

Reviewed upstream notices: https://github.com/HKUDS/nanobot/blob/main/THIRD_PARTY_NOTICES.md
Reviewed REA notices: https://github.com/morluto/rea/blob/main/THIRD_PARTY_NOTICES.md

Examples seen in Nanobot's notices: MIT interface/rendering components and SIL OFL KaTeX fonts. This is not a complete dependency-license audit.
